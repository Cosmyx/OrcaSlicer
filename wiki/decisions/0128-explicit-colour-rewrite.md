# 0128. Explicit colour rewrite, literal rows and snippets

## Status

Accepted.

## Context

The teal appears as `#RRGGBB` in about 80 GUI and web files, and as numbers
(`wxColour(0, 150, 136)`, `ImVec4(0.00f, 0.59f, 0.53f, ...)`, `0x009688`,
`150.f / 255.f`, an ABGR `0xFF889600`) in about 70 more. A recolouring that
guesses (any teal-looking colour becomes violet) would also change filament
colours and 3D highlights, and could not be reviewed.

## Decision

- The hex rewrite (`scripts/cosmyx/branding/colours.py`) changes only the
  mapped colours, in the files of `scopes`, on bytes (any encoding and line
  ending survive). Output is uppercase, an 8-digit colour keeps its alpha,
  and `href`, `url(...)`, URL fragments (a `#` inside a `scheme://...`
  run), numeric character references (`&#NNNNNN;`) and base64 data are never
  touched. The same rule decides what the leftover guards count.
- Numeric forms are `literals` rows with an exact count per file and text,
  applied by the engine before the plugin. The tuple rows (reason starting
  with `tuple `) are generated by `just brand-colour-literals`, which keeps
  the notation of each number; the ABGR integer of `BitmapCache.cpp` is a
  hand-written row.
- `snippets` rows insert one line after an exact anchor. The only one adds
  `replaces["#8000FF"] = "#A472F5"` to the dark map of `BitmapCache.cpp`:
  `std::map` applies the quoted keys first, so the bare key reaches only the
  CSS-form fills the quoted key misses.
- The default filament colour is `#242323` (dark grey, chosen by the user on
  2026-11-25), not the teal and not a violet: `#26A69A` is both the accent
  hover and the colour `PresetBundle.cpp` gives a filament slot that has no
  saved colour. One hand-written literal row replaces exactly that fallback
  (`filament_colors.resize(filament_presets.size(), "#26A69A");`, count 2),
  so the `#26A69A` mapping keeps turning every accent use violet. The option
  default (`#F2754E` in `PrintConfig.cpp` and `AppConfig.cpp`) and the vendor
  profiles are not teal and stay as they are.
- Scopes: `src/slic3r/` C++ and Objective-C++ sources except
  `src/slic3r/GUI/Cosmyx/`, `resources/web/` `.css`, `.html`, `.htm`, `.js`,
  and `src/libslic3r/Color.hpp`. `PresetBundle.cpp` (reached only by the
  default filament colour row above) and the profiles stay out.
- The teal family recogniser never rewrites: it only finds leftovers.

## Consequences

- Every changed byte is traceable to one mapping or one row; an upstream
  change to a counted text stops the build before it writes anything.
- Removing it: delete `colours.py` and `colours.json`; the engine skips the
  colour stage when the table is absent.
