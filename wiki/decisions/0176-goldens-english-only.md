# 0176. Goldens are captured in English only

## Status

Accepted.

## Context

Each language would multiply the goldens; the user said no other language is
planned.

## Decision

- One golden set per OS, in en_US, with the shipped theme (the dark mode is
  forced, decision 0136).

## Consequences

- Adding a language later means a `language` axis in the script and the
  goldens layout.
